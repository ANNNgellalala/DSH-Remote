qrcode-generator — vendored browser library for the DSH Remote pairing page
========================================================================

File:    relay/assets/qrcode.js (unmodified copy of the package's dist/qrcode.js)
Package: qrcode-generator@2.0.4
Source:  https://github.com/kazuhikoarase/qrcode-generator
Fetched: `npm pack qrcode-generator` (npm registry), 2026-11-09

The file is vendored (not imported as a Node module) and served only to
loopback browsers by the relay's pairing page. The relay keeps zero third-party
runtime dependencies: nothing is loaded from npm at runtime.
